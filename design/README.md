# design/

Հաստատված դիզայնի սկզբնական ֆայլերը (Claude Design bundle-ներ,
«Արկոմպ ներարտադրական համակարգ.zip»-ից)։

- `1 - Homepage.html` — իմպլեմենտացված է `src/app/page.tsx`-ում
- `2 - Product page.html` — դեռ իմպլեմենտացված չէ
- `3 - Mobile.html` — բջջային էկրանների ցուցադրություն
- `4 - Design system.html` — գույներ, տիպոգրաֆիա, spacing (տես `globals.css`)
- `5 - Audit.html` — ընթացիկ arkomp.am կայքի վերլուծությունը

Ֆայլերը JS-ով ռենդերվող bundle-ներ են՝ բացվում են բրաուզերում։ Build-ի մեջ
չեն մտնում (`.dockerignore`-ում բացառված են)։
